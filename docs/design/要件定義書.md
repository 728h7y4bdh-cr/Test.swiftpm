## 0. 本書について

本書は、Sample App（Bluetooth通信アプリ）の要件を定義する文書である。

## 1. 概要・開発環境

### 1.1 アプリ概要

| 項目 | 内容 |
|---|---|
| アプリ名 | Sample App |
| 用途 | 2台の端末（iPad／iPhone）を1:1でBluetooth接続し、データの送受信を行う検証用アプリ |
| 対象デバイス | iPad、iPhone |
| 通信方式 | Bluetooth（Bluetooth Low Energy）による1対1通信 |

### 1.2 開発環境

| 項目 | 内容 |
|---|---|
| 開発ツール | Swift Playgrounds（Xcodeは使用しない） |
| UIフレームワーク | UIKit（SwiftUIは使用しない） |
| バージョン管理 | GitHub |
| 対象OS | iOS 17以上 |
| 対応デバイスファミリ | iPad・iPhoneの両方で動作すること |
| 画面回転・マルチタスク | iPadのマルチタスク機能（Slide Over／Split View）を妨げないよう、縦向き・逆さ縦向き・横向き（左右）の4方向すべての画面回転をサポートすること |

## 2. 使用するライブラリ

| 項目 | 内容 |
|---|---|
| 通信方式 | Bluetoothを使用すること |
| Wi-Fi制約 | Wi-Fi機能は常時OFFにすること。通信用ライブラリの選定を含め、Wi-Fiハードウェアには一切関与しないこと |

> 補足：具体的にどのBluetooth関連ライブラリ（Core Bluetooth等）を使用するかは、本書では規定しない。実装時の技術選定はPS設計書0.1節「前提・設計上の補足事項」を参照すること。

## 3. 通信仕様

2台の端末間で送受信するデータは、以下の固定フォーマットに従うこと。

| 項目 | サイズ | 内容 |
|---|---|---|
| 送信種別 | 1byte | 要求時に`0x29`、応答時に`0x92` |
| 通信種別 | 1byte | 通信開始・待受は`0x01`。データ送受信は`0x02` |
| 送信元ID | 3byte | 送信元の端末ID（3桁の数値文字列をASCII変換した値） |
| 送信先ID | 3byte | 送信先の端末ID（3桁の数値文字列をASCII変換した値） |
| 入力データ | 10byte | 用途別のデータ（空きバイトは`0x20`＝半角スペースで埋める） |

- 合計18byte固定長のデータとする。
- 自端末ID・接続先IDは、いずれも3桁の数値文字列（`"000"`〜`"999"`）とする。

## 4. 動作状態（ステータス）

アプリは常にいずれか1つの状態を持ち、以下の状態を遷移すること。状態が変化するタイミングの詳細は、各処理の要件（5章・6章・7章・8章・9章）、および状態遷移の一元管理方針はPS設計書3章を参照すること。

| No | 状態名 | 内容 |
|---|---|---|
| 1 | アイドル | 何も通信していない状態。アプリ起動直後、および通信切断処理完了後 |
| 2 | Bluetooth通信開始処理中 | 通信開始処理（5章）の実行中 |
| 3 | データ送信待ち中 | 通信開始処理の成功後、またはデータ送信完了後、次のデータを送信可能な状態 |
| 4 | Bluetooth通信待受処理中 | 待受開始処理（6章）の実行中 |
| 5 | データ受信待ち中 | 待受処理の成功後、またはデータ受信再開後、データを受信可能な状態 |
| 6 | データ受信停止中 | 受信終了要求を検出してから、受信終了完了を通知するまでの間 |
| 7 | データ送信処理中 | データ送信処理（8章）の実行中 |

## 5. Bluetooth通信開始処理

Bluetooth接続画面の「接続開始」ボタンを押した端末（能動的に相手を探しにいく側）が行う処理。

| 項目 | 内容 |
|---|---|
| 契機 | Bluetooth接続画面の「接続開始」ボタンタップ（自端末IDと接続先IDが一致していないこと） |
| 処理内容 | 接続先の端末を発見し、接続したうえで、通信開始要求（3章の通信種別`0x01`・送信種別`0x29`）を1回送信し、相手からの応答（送信種別`0x92`）を待ち受ける |
| タイムアウト | 「接続開始」ボタンを押した瞬間から60秒。60秒以内に応答を検出できなければ異常終了とする |
| 正常終了時 | データ送信待ち中の状態に遷移し、コール元（画面）に正常終了を通知する |
| 異常終了時 | 通信切断処理（7章）を実行したうえで、コール元に異常終了を通知する |

## 6. Bluetooth待受開始処理

Bluetooth接続画面の「待受開始」ボタンを押した端末（受動的に相手を待ち受ける側）が行う処理。

| 項目 | 内容 |
|---|---|
| 契機 | Bluetooth接続画面の「待受開始」ボタンタップ（自端末IDと接続先IDが一致していないこと） |
| 処理内容 | 通信開始要求（3章の通信種別`0x01`・送信種別`0x29`）の受信を待ち受け、検出したら応答（送信種別`0x92`）を1回返す |
| タイムアウト | 「待受開始」ボタンを押した瞬間から60秒。60秒以内に要求を検出できなければ異常終了とする |
| 正常終了時 | データ受信待ち中の状態に遷移し、コール元（画面）に正常終了を通知する |
| 異常終了時 | 通信切断処理（7章）を実行したうえで、コール元に異常終了を通知する |

## 7. Bluetooth通信切断処理

現在確立しているBluetooth接続を切断し、状態をアイドルに戻す処理。以下のいずれの契機でも実行される共通処理とする。

| No | 契機 |
|---|---|
| 1 | Bluetooth通信開始処理（5章）／Bluetooth待受開始処理（6章）の開始時、既に接続中の端末がある場合の前処理として |
| 2 | Bluetooth通信開始処理・Bluetooth待受開始処理・データ送信処理（8章）・データ受信処理（9章）のいずれかが異常終了した場合 |
| 3 | データ送信画面・データ受信画面で「戻る」ボタンが押された場合 |
| 4 | 12章の「予期しない切断」を検出した場合 |

| Step | 処理内容 |
|---|---|
| 1 | Bluetoothの接続を切断する |
| 2 | 状態をアイドルに初期化する |

## 8. データ送信処理

データ送信画面から呼び出される、Central役（通信開始処理を行った側）のみが実行する処理。

| 項目 | 内容 |
|---|---|
| 契機 | データ送信画面の「送信」ボタンタップ |
| 送信データ | 選択したテストデータ（`"YAMA"`または`"KAWA"`）を3章のフォーマットに従い1回送信する（空きバイトは`0x20`埋め） |
| 正常終了時 | コール元（画面）に正常終了を通知する |
| 異常終了時 | 通信切断処理（7章）を実行したうえで、コール元に異常終了を通知する |

## 9. データ受信処理

データ受信画面から呼び出される、Peripheral役（待受開始処理を行った側）のみが実行する処理。

| 項目 | 内容 |
|---|---|
| 契機 | データ受信画面への遷移直後、および「受信再開」ボタンタップ時 |
| チェック内容 | 受信したデータの送信元ID・送信先ID・入力データ（`"YAMA"`または`"KAWA"`であること）を確認する |
| チェックOK時 | コール元（画面）に「受信検出あり」を通知する（受信データを含む） |
| チェックNG時 | コール元（画面）に「受信検出なし」を通知する（通信は切断せず、受信処理を継続する） |
| 受信終了要求時 | 受信処理を終了し、コール元に「受信終了完了」を通知する |

## 10. 初期化処理

| 項目 | 内容 |
|---|---|
| 契機 | アプリ起動時に1度だけ |
| 処理内容 | 状態をアイドルにセットし、自端末IDに`"000"`、接続先IDに`"001"`をセットする |

## 11. 画面仕様

### 11.1 TOP画面

| 項目 | 内容 |
|---|---|
| 表示内容 | 画面中央に文字列「Sample App」を表示する |
| 遷移条件 | 画面表示から5秒経過後、自動的にBluetooth接続画面へ遷移する（TOP画面へは戻れない） |

### 11.2 Bluetooth接続画面

| 項目 | 内容 |
|---|---|
| 表示内容 | 自端末ID・接続先IDの入力欄（初期表示値は内部パラメータの値）、「接続開始」ボタン、「待受開始」ボタン |
| Bluetooth使用許可確認 | 画面遷移時にOS標準の使用許可確認を行い、許可されていない場合は他画面へ遷移させない |
| 入力チェック | 自端末IDと接続先IDが一致している場合、以降の処理には進ませない |
| 「接続開始」ボタン | Bluetooth通信開始処理（5章）を実行する。正常終了後、データ送信画面へ遷移する |
| 「待受開始」ボタン | Bluetooth待受開始処理（6章）を実行する。正常終了後、データ受信画面へ遷移する |

### 11.3 データ送信画面

| 項目 | 内容 |
|---|---|
| 表示内容 | 接続先IDの表示、送信データの選択（`"YAMA"`／`"KAWA"`）、「送信」ボタン、「戻る」ボタン |
| 「送信」ボタン | データ送信処理（8章）を実行する。結果を表示し、画面遷移はしない（連続送信可能） |
| 「戻る」ボタン | データ送信処理中でなければ、通信切断処理（7章）を実行後、Bluetooth接続画面へ戻る。処理中は戻れない |

### 11.4 データ受信画面

| 項目 | 内容 |
|---|---|
| 表示内容 | 受信データ（送信元ID／送信先ID／データ）の表示、「受信再開」ボタン、「戻る」ボタン |
| 画面遷移直後 | データ受信処理（9章）を自動的に開始する |
| 受信検出時 | 受信データを表示し、「受信再開」ボタンを表示する |
| 「戻る」ボタン | データ受信処理の終了を待ってから、通信切断処理（7章）を実行し、Bluetooth接続画面へ戻る |

## 12. エラー・異常時仕様

### 12.1 タイムアウト

Bluetooth通信開始処理（5章）・Bluetooth待受開始処理（6章）は、いずれもボタン押下の瞬間から60秒以内に完了しなければ異常終了とする。

### 12.2 予期しない切断

データ送信画面・データ受信画面の表示中に、相手端末とのBluetooth接続が予期せず切断された（電源OFF・電波切断等）ことを検出した場合、進行中の処理があれば中断したうえで、その旨をユーザーに通知し、Bluetooth接続画面へ戻ること。
