        ┃                                                  ┃
        ┃    ┌──────────┐          ┌──────────┐    ┃
        ┃    │   iPad     │          │  iPhone    │    ┃
        ┃    │  （1台）    │◀━━BLE━━▶│  （1台）    │    ┃

        ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

## 4. 検査項目

### 4.1 TOP画面

#### TOP-01：表示内容確認と5秒後の自動遷移

- **試験目的／確認内容**：TOP画面の表示内容と、5秒経過後の自動画面遷移を確認する
- **試験条件**：端末1台（相手端末は不要）。アプリ未起動の状態
- **試験手順**：
  1. アプリを起動する。
  2. 判定基準1を確認する。
  3. 何も操作せず、画面表示から5秒間待つ。
  4. 判定基準2を確認する。
- **判定基準**：
  1. （手順2にて）画面中央に「BlueCom」が表示されていること。
  2. （手順4にて）5秒経過後、自動的にBluetooth接続画面へ遷移すること。手動操作は不要であること。

### 4.2 Bluetooth接続画面（入力・許可確認）

#### CONN-01：初回起動時のBluetooth使用許可「許可」

- **試験目的／確認内容**：初回のBluetooth使用許可ダイアログで「許可」を選んだ場合の挙動を確認する
- **試験条件**：当該端末でアプリを初めて起動し、OSのBluetooth使用許可状態が未決定であること
- **試験手順**：
  1. TOP画面からBluetooth接続画面へ遷移させる。
  2. OS標準のBluetooth使用許可ダイアログで「許可」を選択する。
- **判定基準**：
  1. ダイアログが閉じ、自端末ID・接続先ID入力欄と「接続開始」「待受開始」ボタンが表示されること。
